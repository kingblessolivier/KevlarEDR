# Security reporting

KevlarEDR is under development. Version 0.1 is a desktop prototype with no
promise of complete malware prevention or recovery.

Use GitHub private vulnerability reporting if enabled. If it is unavailable,
open an issue requesting a private reporting channel **without disclosing the
exploit, sensitive logs, credentials, or real malware**. Do not publish a
working exploit before coordinating with the maintainer.

Include affected version/commit, Windows build, reproduction using disposable
fixtures, expected behavior, observed behavior, and impact. Document paths and
device identifiers can be sensitive; redact them before sharing.

No response-time commitment or bug-bounty program is currently established.
Do not test on computers or networks you are not authorized to administer.
